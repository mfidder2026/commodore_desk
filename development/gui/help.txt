# Commodore Desk 64 - help texts (F1)
# tools/make_help.py turns this into build/helptext.prg (max 4 KB).
# "@<n> <title>" starts context n; the lines below it (max 33 characters,
# max 14 lines) are the help text. Only capitals, digits and punctuation.
# Contexts 0-12 = desktop + app id + 1; 13 and up are sub-screens.

@0 DESKTOP
CLICK AN ICON TO START IT. THE
LIST SCROLLS WITH THE BAR ON THE
RIGHT. MENUS AT THE TOP:
CD64     HELP, RESET, EXIT, ABOUT
DESKTOP  ADD/EDIT/DELETE PROGRAM
FILES    THE FILE MANAGER
SYSTEM   SETTINGS, NETWORK, MAIL,
         TIME

MOUSE, JOYSTICK OR CURSOR KEYS
MOVE THE POINTER; SPACE OR RETURN
CLICKS. ESC CLOSES A PROGRAM.
DRIVE OPENS FILES; DRAG PROGRAMS
TO TRASH (SEE SETTINGS).

@1 FILE MANAGER
TWO PANELS, EACH ON A DRIVE.
CLICK A PANEL OR CRSR RIGHT TO
MAKE IT ACTIVE. CLICK THE HEADER
(8:1541) TO SWITCH DRIVE.
CRSR UP/DOWN SELECTS A FILE.
RUN  RETURN START PRG, PLAY SID,
           EDIT SEQ/CFG/INI/TXT
EDIT F3    OPEN IN TEXT EDITOR
COPY F5    COPY TO OTHER PANEL
DEL  F8    DELETE (ASKS FIRST)
DRIVES F7  LOOK FOR DRIVES AND
           READ DISKS AGAIN
REU/GEORAM SHOW AS RAM DRIVE (R:)

@2 TEXT EDITOR
TYPE TO WRITE. RETURN STARTS A
NEW LINE, DEL DELETES.
CURSOR KEYS MOVE THE CURSOR.

LOAD  OPEN A TEXT FILE
SAVE  WRITE THE TEXT TO DISK
NEW   START AN EMPTY TEXT
FILES OPENED FROM THE FILE
MANAGER ARE SAVED UNDER THEIR
OWN NAME.
ESC CLOSES THE EDITOR.

@3 PAINT
PICK A COLOUR AT THE BOTTOM,
HOLD FIRE OR SPACE TO DRAW.
THE LAST BUTTON IS THE ERASER.
ESC CLOSES PAINT.

@4 CALCULATOR
CLICK THE KEYS TO CALCULATE.
+ - * / WORK ON WHOLE NUMBERS
(0-65535). C CLEARS.
ESC CLOSES THE CALCULATOR.

@5 SETTINGS
THEME     C64, MATRIX, PAPER,
          FREMEN, STONE OR DESK64
SOUND     CLICK SOUND ON/OFF
DRIVE..   ICONS RIGHT OF THE DESK
TRASH     ON/OFF (ALL OFF: WIDE)
BORDER..  CLICK A PART, THEN A
MOUSE     COLOUR IN THE PALETTE
FONT      TEN FONTS (CLICK)
MENU      FILLED OR CLEAR MENUS
CLOCK     CLICK TO SET DATE/TIME
SAVE      WRITES CD64.CFG

@6 NETWORK
FINDS RR-NET, ULTIMATE OR WIC64.
CLICK A VALUE TO CHANGE IT:
IP, MASK, GATEWAY, DNS AND THE
CHAT SERVER (HOST, PORT, KEY).
DHCP     GET THE IP FROM NETWORK
MODELS   PICK THE CHAT MODEL
RESCAN   LOOK FOR HARDWARE AGAIN
DEBUG LOG / VIEW  NETWORK LOG
SAVE     WRITES NET.CFG

@7 PING
CLICK TARGET TO TYPE AN IP
ADDRESS OR A NAME.
START SENDS 4 PINGS AND SHOWS
THE TIME OF EACH ANSWER.
ESC STOPS.

@8 CHAT
TYPE A QUESTION AND PRESS RETURN.
THE ANSWER COMES FROM THE AI
SERVER SET IN SYSTEM - NETWORK.
NEW CHAT FORGETS THE
CONVERSATION.
ESC CLOSES THE CHAT.

@9 BBS CLIENT
CONNECT  CALL THE DEFAULT BBS
ADDRESS BOOK  PICK, ADD OR
         CHANGE A BBS
LOCAL ECHO  SHOW YOUR TYPING
         (FOR BOARDS THAT DON'T)
IN A SESSION:
F7       SESSION MENU:
         D HANG UP, Q DESKTOP,
         X XMODEM DOWNLOAD (PRG)
RUN/STOP SENDS AN ABORT
F1 IS SENT TO THE BBS.

@10 EMAIL
FETCH  GET THE LIST OF MAIL
NEW    WRITE A NEW MESSAGE
CLICK A MESSAGE TO READ IT.
KEYS: F = FETCH, N = NEW.

MAIL STAYS ON THE SERVER.
SETTINGS: SYSTEM - EMAIL.

@11 EMAIL SETTINGS
CLICK A FIELD TO TYPE IT:
YOUR NAME, EMAIL ADDRESS,
POP3 AND SMTP SERVER AND PORT,
USER NAME (EMPTY = ADDRESS),
PASSWORD, TIME ZONE.
NO SSL/TLS: USE A MAILBOX THAT
ALLOWS THAT.
SAVE WRITES MAIL.CFG.

@12 SID PLAYER
THE LIST SHOWS THE SID FILES ON
THE DISK. CLICK ONE TO PLAY IT.
WHILE IT PLAYS:
+ / -    NEXT / PREVIOUS SONG
SPACE    STOP, BACK TO THE LIST
PUT YOUR OWN .SID FILES IN THE
SID FOLDER BEFORE BUILDING.

@13 BBS ADDRESS BOOK
CLICK A BBS: IT BECOMES THE
DEFAULT FOR CONNECT.
ADD     ADD YOUR OWN BBS
EDIT    CHANGE THE SELECTED ONE
DELETE  REMOVE THE SELECTED ONE
ONLY YOUR OWN BBSES CAN CHANGE.
ESC OR X CLOSES THE BOOK.

@14 ADD / EDIT BBS
CLICK A FIELD TO TYPE IT.
NAME      UP TO 20 CHARACTERS
HOST      NAME OR IP ADDRESS
PORT      USUALLY 23 OR 6400
TERMINAL  CLICK: PETSCII/ASCII
SAVE STORES IT IN BBS.BOOK.

@15 READING MAIL
UP/DOWN  PAGE THROUGH THE TEXT
REPLY    ANSWER THIS MESSAGE
BACK     BACK TO THE LIST
KEYS: SPACE = NEXT PAGE,
- = PREVIOUS, R = REPLY.

@16 WRITING MAIL
CLICK TO OR SUBJ TO TYPE THEM,
CLICK THE TEXT TO WRITE.
IN THE TEXT: CURSOR KEYS,
RETURN, DEL, CLR/HOME.
F7 OR RUN/STOP ENDS TYPING.
SEND    SEND THE MESSAGE
CANCEL  THROW IT AWAY

@17 DATE AND TIME
GETS THE DATE AND TIME FROM A
TIME SERVER (NTP) ON THE NET.
TIME ZONE   CLICK TO PICK YOUR
            ZONE. SUMMER TIME IS
            AUTOMATIC.
TIME SERVER DEFAULT POOL.NTP.ORG
SYNC AT START  ON: GET THE TIME
            EACH TIME CD64 STARTS
SYNC NOW    GET THE TIME NOW
SAVE        KEEP THE SETTINGS
NEEDS SYSTEM - NETWORK TO WORK.

@18 SID RADIO
PLAYS RANDOM TUNES FROM THE HVSC
(HIGH VOLTAGE SID COLLECTION) ON
THE INTERNET. PLAY STARTS.
SPACE    NEXT TUNE
RUN/STOP STOP THE RADIO
A TUNE PLAYS UP TO 3 MINUTES.
THE LIST IS RADIO.LST: LINE 1 =
SERVER, THEN ONE TUNE PER LINE.
