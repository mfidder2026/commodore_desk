# SID music

Put `.sid` files (PSID) here. `build_disk.bat` writes every `sid\*.sid` to the
D71, and to the D64 while there is room. The **SID PLAYER** on the desktop
lists and plays them.

The `.sid` files themselves are not in git (`/sid/*.sid` in `.gitignore`):
they are music by other people. A large free collection is the High Voltage
SID Collection (HVSC), <https://www.hvsc.c64.org>.
